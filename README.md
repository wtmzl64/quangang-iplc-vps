## 泉港 IPLC VPS 是一条什么线路

按 Mkcloud 官方产品总览的口径，泉港专线的基本形态是：

- **入口**：泉州电信，直连产品，绑定一个连入省份（可以自行切换绑定省份）
- **出口**：香港 BGP，经多条运营商线路和 PNI 连接向外访问
- **端内参考延迟**：1~2ms（这是产品资料给的端内参考值，不是你家里到香港网站的全程延迟，后面细说）
- **交付形态**：VPS。每台机器分配 1 个独立入口 IP 和 1 个独立出口 IP
- **计费方式**：独享带宽计费，不限流量

这里有个很多人第一次接触专线 VPS 会搞混的点：你连接的是**入口 IP** 来操作机器，而你的业务程序（比如爬虫、客户端工具、店铺运营软件）在 VPS 里发起的访问，会自动从**出口 IP** 走出去。两个 IP 都是独享的，互不混用。

出口方向的定位也要说清楚：这条线是“福建进、香港出”，适合把业务出口放在香港，或者借助福建的地理位置承载对台方向的业务。Mkcloud 官方知识库在聊对台业务时也明确提过，福建（厦门/泉州）与台湾一水之隔，用厦港/泉港高防线承载台湾方向，是地理最近的抗 DDoS 选择。

## 谁真的需要泉港这条线，谁不需要

按官方知识库和第三方攻略文章的口径，泉港 IPLC 的典型使用场景集中在几类：

- **福建本地用户**：泉州及周边的电信宽带用户连泉州电信入口，本地到入口这一段的质量通常更有保障。官方也提醒，同省不代表永远最快，最终要从自己宽带实测。
- **需要高防的业务**：独立站引流、跨境电商店铺运营这类业务，出口 IP 一旦被打，业务就得停摆。泉港这条线自带 DDoS 防护——不同页面口径在 100Gbps 到 300Gbps 级别，而且官方知识库明确说：防护对象、阈值和处置规则暂不公开，有明确防护需求要先通过工单确认，别只看宣传数字下单。
- **对台方向的业务承载**：前面提到，福建到台湾地理最近，这是这条线相对独家的场景。
- **对 IP 独享敏感的运营**：每台机器双独享 IPv4，出口 IP 不与别人共享，这对做平台账号运营的用户是实际需求。

反面同样重要，官方写得很直接，这几类用途不要买：

- 公开建站、收支付回调、邮件接收、对外游戏服务端——**出口 IP 不接受外部连入**，这些用途根本跑不起来
- 机场、回国等违规用途——平台全部专线产品需要中国身份实名，采用省级白名单措施，仅允许绑定的省份 IP 连入

一句话：这是给有正规跨境业务、预算充足、明确需要“福建入口 + 香港出口 + 独享带宽 + 高防”这个组合的用户准备的，不是通用型便宜 VPS。

- **升降级规则**：升级降级都要提交工单，降级到更低价格套餐时差价不退；快照和备份不作为已提供的产品能力，重要数据自己备份。

## 常见问题

**泉港和厦港怎么选？**
看你的接入网络在泉州还是厦门方向，以及本地电信还是多线宽带。两者出口、防护定位、计费方式都一致，差别在入口。拿不准就两条都测，官方支持开通前按产品页配置对比，但注意开通后不能换地域。

**“端内延迟 1~2ms”是我到香港的延迟吗？**
不是。1~2ms 是线路端内的参考值，你的完整耗时还要加上本地宽带到泉州入口、以及香港出口到目标服务的两段路径。官方建议用正常时段和高峰时段分别实测，不要拿端内值当全程 RTT。

**高防能防多大的攻击？**
官方不同页面口径在 100G~300Gbps 级别，但官方知识库同时提醒：具体阈值、保护范围和处置约定需要通过工单确认，不能只看宣传峰值，也不能保证覆盖所有应用层攻击。

**出口 IP 能解锁流媒体吗？**
官方明确不承诺。当前交付的是服务器 IP，不保证原生、住宅或流媒体解锁属性，也不要为了这类未承诺的属性下单。

**能当机场或回国节点用吗？**
不能。平台要求实名，所有专线产品采用省级白名单措施，明确为防止机场、回国等违规用途而设，条款写得很清楚。

**预算不够独享档怎么办？**
看共享款。广港 IEPL、沪港 IPLC、深港 IX 都有流量计费套餐，158~358 元/月起步，区别是共享带宽为峰值、按双向流量计费、超量暂停。如果业务不依赖独享 IP 和高防，共享款足够用。
